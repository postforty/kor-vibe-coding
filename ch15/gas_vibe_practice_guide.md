# 📱 [바이브 코딩 실습 가이드] 구글 시트 & 드라이브 연동 '스마트 영수증 가계부' 만들기

본 실습 교안은 **Google Apps Script(GAS)와** **Clasp CLI**를 활용하여, 별도의 서버나 DB 비용 없이 **Google Sheets(지출 장부 DB) + Google Drive(영수증 사진 스토리지) + Apps Script(웹 서버)를** 연동한 **'스마트 영수증 가계부'**를 AI 에이전트와 함께 구축하는 실습 가이드입니다.

---

## 💡 1. 실습 아이템: 📸 스마트 영수증 가계부 (Smart Receipt Ledger)

### 🎯 왜 '영수증 가계부'인가요?
1. **남녀노소 누구나 직관적인 도메인**: 복잡한 업무 지식 없이 **"지출 내역 기록 + 영수증 사진 첨부"**라는 가장 대중적이고 명확한 흐름으로 실습에 100% 몰입할 수 있습니다.
2. **구글 3대 인프라의 완벽한 결합**:
   - 📊 **Google Sheets**: 지출 일자, 분류(식비/교통비/쇼핑 등), 금액, 사용처, 결제수단 자동 기록
   - 📂 **Google Drive**: 스마트폰으로 찍은 **영수증 사진/캡처 이미지를 자동 보관**하고 시트에 바로가기 링크 생성
   - 🌐 **Apps Script Web App**: 모바일과 PC 브라우저에서 누구나 간편하게 접속하는 가계부 입력 웹앱
3. **바이브 코딩의 본질에 집중**:
   - 복잡한 비즈니스 룰 고민을 덜어내고, **"AI에게 PRD 요구사항 지시 → 코드 생성 → Clasp 배포 → 스프레드시트/드라이브 연동 검증"**의 핵심 개발 루프를 가장 빠르고 깔끔하게 체득합니다.

## 🛠️ 3. 단계별 상세 실습 가이드

### 📍 STEP 1. 클라우드 인프라 연동 (40분)

#### 1. Google Apps Script API 켜기
- [Google Apps Script 설정 페이지](https://script.google.com/home/usersettings) 접속
- **`Google Apps Script API`** 항목을 **`사용함 (ON)`**으로 전환합니다.

#### 2. Clasp 글로벌 설치 및 로그인
터미널(PowerShell 또는 cmd)에서 실행:
```bash
# clasp 전역 설치
npm install -g @google/clasp

# 구글 계정 로그인 (브라우저 열리면 권한 허용)
clasp login
```

#### 3. 구글 스프레드시트 & 영수증 폴더 준비
1. [구글 드라이브](https://drive.google.com)에서 **새 스프레드시트** 생성 (제목: `나만의_스마트_가계부`).
   - 브라우저 주소창에서 스프레드시트 ID 복사: `https://docs.google.com/spreadsheets/d/`**`[이 부분이 스프레드시트 ID]`**`/edit`
2. 구글 드라이브에 **새 폴더** 생성 (제목: `가계부_영수증_보관함`).
   - 해당 폴더의 **공유 링크 또는 주소창 URL**을 복사해 둡니다.

#### 4. 로컬 프로젝트 생성 및 연결
```bash
mkdir smart-ledger && cd smart-ledger
```

**[AI에게 지시할 프롬프트: 프로젝트 설정 파일 생성]**
> "Node.js 기반 Clasp 프로젝트를 위한 `package.json`과 `.clasp.json` 파일을 작성해줘. 
> package.json에는 `push`, `pull`, `open` npm 스크립트를 포함하고, .clasp.json에는 parentId로 나의 스프레드시트 ID `[스프레드시트ID]`를 연결해줘."

생성된 `.clasp.json` 예시:
```json
{
  "scriptId": "YOUR_SCRIPT_ID",
  "parentId": ["YOUR_SPREADSHEET_ID"]
}
```

### 📍 STEP 2. 바이브 코딩으로 가계부 풀스택 구현 (60분)

#### 1. 백엔드 로직 지휘 (`Code.js`)

**[AI 프롬프트: 가계부 백엔드 Code.js 생성]**
```text
너는 Google Apps Script(GAS) 시니어 엔지니어야.
구글 스프레드시트를 장부 DB로, 구글 드라이브를 영수증 사진 보관함으로 사용하는 '스마트 영수증 가계부' 백엔드(Code.js)를 작성해줘.

[필수 기능 요구사항]
1. setupSheets():
   - '설정', '지출내역', '카테고리별통계' 3개 시트를 자동 생성.
   - '설정' 시트: A4="영수증 드라이브 폴더 URL", A5="웹앱 배포 URL" 라벨 배치 및 B열 입력 안내 서식.
   - '지출내역' 시트: 헤더(등록일시, 지출일자, 분류, 사용처, 금액, 결제수단, 메모, 영수증링크) 생성 및 헤더 배경색(부드러운 민트/그레이), 고정틀 설정.

2. getTargetDriveFolder():
   - '설정' 시트 B4 셀의 드라이브 URL에서 폴더 ID를 정규식으로 추출하여 DriveApp 폴더 객체를 반환.

3. submitExpense(payload):
   - 전달 데이터: date(지출일), category(식비/교통/쇼핑/문화/기타), title(사용처), amount(금액), payMethod(카드/현금/페이), memo(메모), receiptData(Base64 이미지, 선택사항).
   - receiptData가 있으면 getTargetDriveFolder() 폴더에 영수증 이미지 파일(파일명: YYYYMMDD_사용처_금액.jpg)로 저장하고 드라이브 다운로드 URL 생성.
   - '지출내역' 시트 다음 행에 타임스탬프와 함께 모든 데이터를 추가 (금액 열은 원화 통화 서식 적용).
   - 성공 메시지 반환.

4. getRecentExpenses(limit):
   - 최근 등록된 지출 내역 상위 5~10개를 조회하여 배열로 반환.

5. doGet():
   - HtmlService를 이용해 Index.html을 렌더링 (setXFrameOptionsMode: ALLOWALL, 모바일 viewport 메타태그 추가).
```

#### 2. 프론트엔드 UI 지휘 (`Index.html`)

**[AI 프롬프트: 모바일 최적화 Index.html 생성]**
```text
Google Apps Script 웹 앱에서 렌더링될 모바일 최적화 '스마트 영수증 가계부' UI(Index.html)를 작성해줘.
HTML, CSS, JavaScript가 하나의 파일에 포함되어야 해.

[디자인 & UX 요구사항]
1. 모던 핀테크 앱 느낌(토스/카카오뱅크 스타일)의 깔끔하고 감각적인 디자인 (부드러운 라운딩, 파스텔 포인트 컬러).
2. 상단 헤더: "📸 스마트 영수증 가계부" 및 오늘 날짜 표시.
3. 지출 등록 폼:
   - 지출 일자 (기본값 오늘)
   - 카테고리 선택 버튼 (🍽️ 식비, 🚗 교통, 🛍️ 쇼핑, ☕ 카페/간식, 🎬 문화, 💡 기타)
   - 금액 입력 (숫자 입력 시 자동으로 1,000 단위 콤마 포맷팅)
   - 사용처 및 결제수단(신용카드, 체크카드, 간편결제, 현금)
   - 📸 영수증 사진 첨부 (모바일에서 카메라 촬영 또는 갤러리 사진 선택 가능하도록 <input type="file" accept="image/*" capture="environment"> 지원)
   - 영수증 사진 미리보기 기능
   - 메모 입력 (선택)
4. 제출 인터랙션:
   - "지출 기록하기" 버튼 클릭 시 FileReader로 이미지를 Base64 변환하여 google.script.run.submitExpense() 비동기 호출.
   - 로딩 스피너 및 진행 상태("영수증 업로드 중...") 표시.
   - 완료 시 상단 토스트 메시지("지출이 성공적으로 기록되었습니다!") 노출 및 폼 리셋.
5. 하단 섹션:
   - "최근 지출 내역" 카드 리스트 (google.script.run.getRecentExpenses() 호출 결과 렌더링).
```

### 📍 STEP 3. 배포 및 초기화 자동화 (40분)

#### 1. 구글로 코드 업로드
```bash
clasp push
```

#### 2. 에디터 열기 및 최초 권한 승인
```bash
clasp open
```
1. Apps Script 에디터 상단 함수 목록에서 **`setupSheets`**를 선택하고 **[실행]**을 클릭합니다.
2. **권한 검토** 팝업이 뜨면:
   - 본인 구글 계정 선택 → `고급` 클릭 → `(안전하지 않음)으로 이동` 클릭 → `허용` 클릭.
3. 구글 스프레드시트로 이동하여 `설정`, `지출내역`, `카테고리별통계` 시트가 자동으로 예쁘게 구성되었는지 확인합니다.

#### 3. 웹 앱(Web App) 배포
1. Apps Script 에디터 우측 상단 **[배포]** → **[새 배포]** 클릭.
2. 톱니바퀴 아이콘 → **웹 앱 (Web App)** 선택.
   - **설명**: `v1.0 영수증 가계부`
   - **다음 사용자로 실행**: `나 (Me)`
   - **액세스 권한을 가진 사용자**: **`모든 사용자 (Anyone)`** *(로그인 없이 편리하게 쓰기 위해 필수)*
3. **[배포]** 클릭 후 발급된 **웹 앱 URL**을 복사합니다.

#### 4. 환경 변수 연결
구글 스프레드시트의 **`설정`** 탭으로 이동하여 입력:
- **B4 셀**: STEP 1에서 만든 **영수증 드라이브 폴더 URL** 붙여넣기
- **B5 셀**: 방금 발급받은 **웹 앱 URL** 붙여넣기

### 📍 STEP 4. E2E 실전 테스트 & 동기화 확인 (50분)

#### 1. 실전 지출 등록 테스트
1. 복사한 웹 앱 URL에 PC 브라우저 또는 **스마트폰**으로 접속합니다.
2. 지출 정보를 입력하고, 영수증(또는 주변 소품) 사진을 찰칵 찍어 첨부한 뒤 **[지출 기록하기]**를 누릅니다.
3. **결과 확인**:
   - 📊 **구글 시트 `지출내역`**: 방금 등록한 금액, 사용처, 카테고리와 함께 영수증 다운로드 링크가 실시간으로 입력되었는지 확인.
   - 📂 **구글 드라이브 `가계부_영수증_보관함`**: 방금 올린 영수증 사진 파일이 깔끔하게 저장되어 있는지 확인.

## 🚨 5. 문제 해결 (Troubleshooting Guide)

| 증상 / 에러 메시지 | 원인 | 해결 방법 |
| :--- | :--- | :--- |
| `User has not enabled the Google Apps Script API` | 구글 계정의 Apps Script API가 꺼져 있음 | [설정 링크](https://script.google.com/home/usersettings)에서 API 상태를 **ON**으로 변경 후 다시 `clasp push` |
| 배포 URL 접속 시 로그인 창이 뜨거나 권한 없음 | 웹앱 배포 권한 설정 미흡 | 배포 관리 → 액세스 권한을 **`모든 사용자(Anyone)`**로 수정 후 새 버전으로 재배포 |
| 영수증 사진을 올렸는데 드라이브에 저장되지 않음 | B4 셀에 드라이브 폴더 URL 누락 | 스프레드시트 `설정` 시트 B4 셀에 구글 드라이브 폴더 URL이 올바르게 적혀있는지 확인 |
| 코드 수정 후에도 웹 앱 화면이 바뀌지 않음 | 웹 앱 버전 미갱신 | `clasp push` 후 Apps Script 에디터 **[배포 관리]**에서 **새 버전(New Version)**으로 업데이트 배포 |
