# 📱 스마트 영수증 가계부 (Smart Receipt Ledger)

Google Apps Script (GAS V8), Google Sheets, Google Drive API, Clasp CLI 기반의 **서버리스 모바일 영수증 가계부**입니다.

---

## 🏗️ 1. 프로젝트 파일 구성

```text
smart-ledger/
├── .clasp.json          # 스프레드시트 ID 바인딩 설정
├── appsscript.json      # Google Apps Script 런타임 및 권한 설정
├── Code.js              # 백엔드 비즈니스 로직 및 Sheets/Drive 연동 API

├── package.json         # Clasp 스크립트 및 의존성
└── README.md            # 배포 및 실행 가이드 (본 문서)
```

## 🚀 2. 원클릭 배포 & 실행 가이드 (3단계)

### 1단계: 클라우드로 코드 푸시 (`clasp push`)
1. [`.clasp.json`](file:///c:/Users/up/Documents/GitHub/kor-vibe-coding/ch15/smart-ledger/.clasp.json) 파일을 열고, `scriptId` 값에 본인의 Google Apps Script **스크립트 ID**를 입력합니다.
   *(스프레드시트 → 확장 프로그램 → Apps Script → 좌측 톱니바퀴 [프로젝트 설정] → `스크립트 ID` 복사)*
2. VS Code 터미널 또는 PowerShell에서 `smart-ledger` 폴더로 이동 후 아래 명령어를 실행합니다:

```bash
cd smart-ledger
npx clasp push
```
> *(안내 팝업 시 `y` 입력 후 `Pushed 3 files.` 확인)*

---

### 2단계: 스프레드시트 원클릭 자동 초기화 (`setupSheets`) & 환경 설정
1. Apps Script 에디터를 엽니다:
   - 현재 연결된 **스프레드시트 화면** 상단 메뉴에서 **[확장 프로그램]** ➡️ **[Apps Script]** 를 클릭합니다.
   - (또는 터미널에서 `npx clasp open` 입력)
2. 에디터 상단의 함수 선택 드롭다운 창에서 **`setupSheets`**를 선택하고 **[▶ 실행]** 버튼을 클릭합니다.
3. 최초 1회 **권한 검토** 팝업이 뜹니다:
   - `계정 선택` → `고급` → `스마트영수증가계부_백엔드(으)로 이동(안전하지 않음)` 클릭
   - ⚠️ 권한 목록 상단의 **[모두 선택] 체크박스를 반드시 체크**한 후 `[계속]` 또는 `[허용]`을 누릅니다.
4. 실행 완료 후 다시 **스프레드시트 화면**으로 돌아가보면 비어있던 시트에 `설정`, `지출내역`, `카테고리별통계` 3개 탭이 완벽한 서식으로 자동 생성된 것을 확인할 수 있습니다.
5. **구글 드라이브 영수증 저장 폴더 연결**:
   - [Google Drive](https://drive.google.com/)에서 영수증을 보관할 새 폴더(예: `스마트가계부_영수증`)를 생성합니다.
   - 폴더에 진입 후 브라우저 주소창의 폴더 URL을 복사하여 스프레드시트 **`설정`** 탭의 **B4 셀 (영수증 드라이브 폴더 URL)**에 붙여넣습니다.

> 🔒 **보안 팁 (GitHub 배포 시 주의사항)**:
> 개인 구글 드라이브 폴더 URL에는 고유 식별자(Folder ID)가 포함되어 있으므로 `Code.js` 소스 코드에 직접 하드코딩하여 GitHub에 커밋하지 않는 것이 안전합니다. 본 프로젝트는 소스 코드를 비워두고 스프레드시트의 `설정` 탭(B4 셀)에서 동적으로 불러오도록 설계되어 있어 안전하게 공개 레포지토리를 유지할 수 있습니다.

---

### 3단계: 웹 앱(Web App) 배포 및 URL 확인
1. Apps Script 에디터 우측 상단 **[배포]** → **[새 배포]**를 클릭합니다.
2. 유형 선택(톱니바퀴)에서 **`웹 앱 (Web App)`**을 선택합니다:
   - **설명**: `v1.0 영수증 가계부`
   - **다음 사용자로 실행**: **`나 (Me)`**
   - **액세스 권한을 가진 사용자**: **`모든 사용자 (Anyone)`** *(모바일에서 로그인 없이 편리하게 쓰기 위해 필수)*
3. **[배포]** 버튼을 클릭하고 발급된 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.
4. 구글 스프레드시트의 **`설정`** 탭 **B5 셀**에 복사한 웹앱 URL을 붙여넣습니다.

## 📱 3. 모바일에서 실전 테스트하기

1. 복사한 웹앱 URL을 스마트폰의 카카오톡, 메시지 또는 브라우저 주소창에 붙여넣습니다.
2. **사파리(iOS)**: 하단 공유 버튼 → `[홈 화면에 추가]`  
   **크롬(Android)**: 상단 메뉴(⋮) → `[홈 화면에 추가]`
3. 영수증 또는 소품을 카메라로 즉시 촬영하고 지출 금액(예: 15,000원)을 등록합니다.
4. **동기화 검증**:
   - 📱 **모바일 화면**: 토스트 알림 노출 & 최근 내역에 썸네일/카드 추가 확인
   - 📊 **구글 시트**: `지출내역` 탭에 새 행과 `📸 영수증 보기` 하이퍼링크 생성 확인
   - 📂 **구글 드라이브**: 영수증 폴더에 `YYYYMMDD_사용처_금액원.jpg` 이미지 파일 생성 확인
