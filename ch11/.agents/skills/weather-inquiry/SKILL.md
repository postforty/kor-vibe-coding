# Weather Inquiry Skill

사용자가 특정 지역의 현재 날씨를 물어볼 때 다음 단계를 따르세요:

## 실행 단계
1. 사용자가 날씨를 알고 싶어 하는 지역을 파악합니다.
2. `run_command` 도구를 사용하여 이 스킬에 포함된 파이썬 스크립트를 실행합니다. 
   - 명령어: `python .agents/skills/weather-inquiry/scripts/get_weather.py "[지역명]"`
   - 실행 위치: 워크스페이스(프로젝트) 루트 디렉터리를 기준으로 명령어를 실행하세요.
   - 주의: 스크립트 실행에 필요한 라이브러리가 없다면 `pip install requests geopy`를 실행하세요.
   - 주의: 스크립트 실행 전 `OPENWEATHERMAP_API_KEY` 환경 변수가 설정되어 있어야 합니다. 설정되어 있지 않다면(혹은 스크립트 실행 결과 환경 변수 오류가 발생한다면) 사용자에게 OpenWeatherMap API 키를 요청하거나 환경 변수에 설정해 달라고 안내하세요.
3. 스크립트의 출력 결과를 분석하여 현재 기온, 날씨 상태, 체감 온도, 습도 등 유용한 정보를 추출합니다.
4. 스크립트 출력 정보를 바탕으로 사용자에게 자연스러운 한국어로 날씨 정보를 제공합니다. 

## 참고 사항
- 스크립트는 `geopy` 모듈을 이용해 위치의 위경도를 찾고, `OpenWeatherMap API`를 통해 날씨 데이터를 가져옵니다.
- 기온 외에도 체감 온도나 습도 등 도움이 될 만한 정보를 답변에 포함하면 좋습니다.
