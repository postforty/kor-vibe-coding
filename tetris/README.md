# 🎮 Python 테트리스 게임 (Pygame)

Pygame 기반으로 제작된 모던한 테트리스 게임입니다.

---

## 🚀 실행 방법

### 1. 가상환경 또는 패키지 설치
Pygame 라이브러리가 필요합니다:
```bash
pip install -r requirements.txt
```
또는
```bash
pip install pygame
```

### 2. 게임 실행
`tetris` 폴더 내에서 다음 명령어를 실행합니다:
```bash
python main.py
```

---

## 🕹️ 조작 방법

| 키 | 동작 |
| :--- | :--- |
| **`←` / `→`** | 블록 좌/우 이동 |
| **`↑`** | 시계 방향 회전 |
| **`Z`** | 반시계 방향 회전 |
| **`↓`** | 소프트 드롭 (천천히 낙하) |
| **`Space`** | 하드 드롭 (즉시 바닥으로 낙하) |
| **`C` / `Shift`** | 블록 홀드 (HOLD) |
| **`P` / `ESC`** | 일시정지 (PAUSE) |
| **`R`** | 게임 재시작 (GAME OVER 시) |

---

## ✨ 주요 기능
- **표준 7종 테트로미노 및 7-Bag 시스템** 탑재 (공정한 블록 스폰)
- **고스트 피스 (Ghost Piece)**: 블록이 착지할 위치를 반투명으로 가이드
- **홀드 (Hold) & 넥스트 (Next)** 블록 미리보기
- **레벨 및 점수 시스템**: 라인을 지울 때마다 점수 획득 및 레벨 업에 따른 속도 증가
- **벽 차기 (Wall Kick)** 및 깔끔한 다크 테마 UI
