# ⚡ AI 대화 필수 마크다운 (핵심 9개)

AI와 대화할 때 딱 이 **9가지**만 알면 충분합니다.

| 기호 | 문법 | 예시 | 미리보기 | AI에게 쓸 때 효과 |
|:---:|:---|:---|:---|:---|
| `#` | **역할 부여** | `# 요리사` | <b style="font-size:1.25em;">요리사</b> | AI에게 **역할(페르소나)** 을 지정해 답변 전문성 상승 |
| `-` | **조건 목록** | `- 소금 넣지 말 것`<br>`- 3줄 이내 요약` | • 소금 넣지 말 것<br>• 3줄 이내 요약 | 요구조건을 정리해 AI가 **조건을 빼먹지 않음** |
| `- [ ]` | **체크리스트** | `- [x] 장보기`<br>`- [ ] 요리하기` | ☑ 장보기<br>☐ 요리하기 | AI에게 **할 일 목록이나 진행 상태**를 요청할 때 사용 |
| `**` | **필수 강조** | `**절대 환각 금지**` | **절대 환각 금지** | **가장 중요한 규칙**을 AI가 잊지 않도록 강하게 주입 |
| `>` | **참고 자료** | `> 참고 뉴스: 인공지능이...` | <blockquote style="margin:0; padding-left:8px;">참고 뉴스: 인공지능이...</blockquote> | 내 질문과 AI가 읽을 **참고 자료(원문)를 구분** |
| `` ` `` | **인라인 코드** | `` `app.py` 파일 수정 `` | `app.py` 파일 수정 | 파일명·변수명·명령어를 **일반 단어와 명확히 구분** |
| ` ``` ` | **코드 상자** | ` ```python`<br>`print("안녕")`<br>` ``` ` | <code>print("안녕")</code> | 프로그래밍 코드나 데이터를 **깨짐 없이 원본 보존** |
| <code>&#124;</code> | **표 (테이블)** | <code>&#124; 항목 &#124; 내용 &#124;</code><br><code>&#124;---&#124;---&#124;</code><br><code>&#124; 사과 &#124; 1000원 &#124;</code> | <table><tr><th>항목</th><th>내용</th></tr><tr><td>사과</td><td>1000원</td></tr></table> | 비교 분석이나 보고서를 **깔끔한 표로 출력 요청** |
| `---` | **구분선** | `---` | <hr style="margin:4px 0;"> | 역할, 지시문, 참고문헌 등 **주제별 문맥을 깔끔하게 분리** |

---

> 💡 **딱 한 줄 팁**: 모든 기호(` # `, ` - `, ` > `) 뒤에는 **스페이스(한 칸 띄어쓰기)**를 꼭 넣어주세요!
