# 마크다운 강조 규칙 (GFM 렌더링 깨짐 방지)

GitHub 마크다운(GFM) 파서 렌더링 버그 방지를 위해, **조사 유무나 위치와 무관하게 예외 없이 아래 대원칙을 적용**합니다.

**대원칙: 강조 기호(`**`) 안에는 백틱(`` ` ``), 따옴표(`'`, `"`), 괄호(`()`, `[]`)를 절대 포함하지 않습니다.**

| 구분 | 금지 패턴 (❌ 예외 없이 금지) | 정상 작성법 (⭕ 권장) |
| :--- | :--- | :--- |
| **인라인 코드** | `` **`SELECT`** ``, `` **`JOIN` 문법**을 `` | `` `SELECT` ``, `<b>`SELECT`</b>`, `` `JOIN` **문법**을 `` |
| **따옴표** | `**"회원"**`, `**'결제'**로` | `"**회원**"`, `'**결제**'로` |
| **괄호·영문** | `**조인(JOIN)**`, `**교집합(`INTERSECT`)**` | `**조인**(JOIN)`, `**교집합**(`INTERSECT`)` |
| **링크** | `**[연습문제](URL)**` | `[**연습문제**](URL)` |

> 💡 **인라인 코드 굵게 표기 요령**: 백틱 자체로 이미 시각적 강조가 되므로 `**`를 씌우지 않으며, 꼭 굵게 해야 할 때는 HTML 태그(`<b>`코드`</b>`)를 사용합니다.
