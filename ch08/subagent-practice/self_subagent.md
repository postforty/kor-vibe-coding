---

### 📌 `self` 서브에이전트 실습 4단계 가이드

#### 1단계: `self` 서브에이전트 개념 이해
`self` 서브에이전트는 **메인 에이전트(Antigravity) 자신을 똑같이 하나 더 복제(Clone)**한 에이전트입니다.
* 메인 에이전트와 **동일한 능력, 동일한 도구(파일 생성/수정, 명령어 실행 등)**를 보유합니다.
* 메인 대화창을 어지럽히지 않고, **독립된 백그라운드 세션에서 코드 작성/수정/테스트를 병렬로 진행**시킬 때 사용합니다.

---

#### 2단계: 채팅창에 프롬프트 입력하기
아래 예시 프롬프트 중 하나를 복사하여 채팅창에 입력해 보세요.

* **예시 A (독립 세션에서 파일 생성 및 코드 작성)**:
  > `"self 서브에이전트를 구동해서 현재 프로젝트에 간단한 hello.js (또는 test.md) 파일을 만들고 예시 코드를 작성해줘."`

* **예시 B (독립 세션에서 코드 분석 및 리팩토링)**:
  > `"self 서브에이전트를 호출해서 프로젝트 내의 코드 포맷팅 상태를 검사하고 결과만 보고해줘."`

---

#### 3단계: 실행 과정 관찰하기
1. **분신 에이전트 생성**: 메인 에이전트가 `self` 서브에이전트를 생성합니다.
2. **독립 작업 진행**:
   * 서브에이전트 패널(또는 CLI `Alt+J`)을 열어보면 메인 에이전트와 동일한 서브에이전트가 별도의 깨끗한 세션에서 파일 생성 및 수정 도구를 호출하는 모습을 확인할 수 있습니다.

---

#### 4단계: 결과 확인
* `self` 서브에이전트가 작업을 완수하면 **Idle** 상태로 바뀌고, 메인 대화창으로 작성된 코드나 파일 결과가 전달됩니다.

---
