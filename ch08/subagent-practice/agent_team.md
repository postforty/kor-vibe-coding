# 소프트웨어 개발 AI 에이전트 팀 구성 Guide

이 문서는 소프트웨어 개발 프로젝트 수행 시 활용할 수 있는 **AI 에이전트 팀 역할 정의 및 구성 전략**입니다.

---

## 1. 전체 단계별 AI 에이전트 분류 (가용 에이전트 전체 목록)

프로젝트 전체 라이프사이클에 맞춰 세분화된 에이전트 역할 목록입니다.

### 1) 관리 및 총괄
* **오케스트레이터 에이전트 (Orchestrator Agent / PM)**
  * 프로젝트 총괄, 요구사항 분석, 작업 분해(WBS) 및 에이전트 간 작업 조율

### 2) 기획 및 요구사항 분석
* **기획 에이전트 (Product Owner / BA)**
  * 비즈니스 요구사항 정의, 기능 상세화 및 와이어프레임 사양 작성
* **리서치 에이전트 (Market & User Research Agent)**
  * 시장 조사, 사용자 니즈 분석 및 경쟁사 리서치

### 3) 설계 및 아키텍처
* **시스템 아키텍트 에이전트 (System Architect Agent)**
  * 전체 시스템 아키텍처 설계, 기술 스택 선정 및 API 명세 정의
* **데이터 아키텍트 에이전트 (Data Architect Agent)**
  * 데이터베이스 schema 모델링 및 데이터 흐름 설계

### 4) 디자인
* **UI/UX 디자이너 에이전트 (UI/UX Design Agent)**
  * 화면 레이아웃, 디자인 시스템/스타일 가이드 및 UI 컴포넌트 규격 정의

### 5) 소프트웨어 개발
* **프런트엔드 개발 에이전트 (Frontend Developer Agent)**
  * UI/UX 구현, 클라이언트 비즈니스 로직 및 상태 관리 작성
* **백엔드 개발 에이전트 (Backend Developer Agent)**
  * 서버 비즈니스 로직 구현, REST/GraphQL API 개발 및 데이터베이스 연동
* **DBA 에이전트 (Database Administrator Agent)**
  * DB 쿼리 최적화, 마이그레이션 관리 및 데이터베이스 성능 튜닝

### 6) 인프라 및 운영
* **DevOps 에이전트 (DevOps / Infrastructure Agent)**
  * CI/CD 파이프라인 구축, 클라우드 인프라(IaC) 관리 및 배포 자동화
* **보안 에이전트 (Security & Compliance Agent)**
  * 취약점 점검, 보안 규정 준수 검토 및 시크릿 관리

### 7) 품질 관리 및 검증
* **QA & 코드 리뷰 에이전트 (QA & Code Reviewer Agent)**
  * 코드 정적 분석, 코드 리뷰, 버그 탐지 및 품질 가이드라인 점검
* **테스트 자동화 에이전트 (Test Automation Agent)**
  * 단위/통합/E2E 테스트 시나리오 작성 및 자동화 테스트 실행

## 2. 최소/핵심 AI 에이전트 구성 (경량화 추천 조합)

초기 및 중소규모 프로젝트에서 효율적으로 활용할 수 있는 **7대 핵심 에이전트 조합**입니다. *(DevOps, DBA, 보안 등의 역할은 아키텍트 및 백엔드 에이전트에 통합하여 운영합니다.)*

| No | 에이전트 명칭 | 주요 역할 및 담당 업무 |
|:---:|:---|:---|
| 1 | **오케스트레이터 에이전트**<br>*(Project Manager)* | 요구사항 분석, 작업 분해, 프로세스 총괄 및 에이전트 간 업무 조율 |
| 2 | **기획 에이전트**<br>*(Product Owner)* | 기능 정의, 요구사항 상세화, 와이어프레임 텍스트 사양 작성 |
| 3 | **시스템 아키텍트 에이전트**<br>*(System Architect)* | 전체 시스템 구조 설계, 데이터 모델링, API 명세서 정의 |
| 4 | **UI/UX 디자이너 에이전트**<br>*(UI/UX Designer)* | 화면 레이아웃, 디자인 스타일 가이드 및 UI 컴포넌트 규격 정의 |
| 5 | **프런트엔드 개발 에이전트**<br>*(Frontend Developer)* | 사용자 인터페이스(UI) 구현 및 클라이언트측 로직 작성 |
| 6 | **백엔드 개발 에이전트**<br>*(Backend Developer)* | 비즈니스 로직, REST/GraphQL API 구현 및 DB 쿼리 연동 |
| 7 | **QA & 코드 리뷰 에이전트**<br>*(QA & Code Reviewer)* | 코드 정적 분석, 버그 검출, 테스트 코드 작성 및 품질 검증 |

> 💡 **Tip:** 프로젝트 규모가 커지거나 특정 영역의 전문성이 요구될 경우, **`1. 전체 분류`**의 전담 에이전트(DevOps, 보안, DBA 등)를 단계적으로 추가하는 것을 권장합니다.
